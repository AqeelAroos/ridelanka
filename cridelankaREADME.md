# 🏍️ RideLanka

> Sri Lanka's premier biker community platform

## About
RideLanka is a full-stack web app built for Sri Lankan motorcycle riders. Discover scenic routes, report road hazards, connect with the biker community, track your rides, and monitor helmet health with AI-powered scalp scanning.

## Features
- 🗺️ Route Explorer — discover and share scenic Sri Lanka rides
- ⚠️ Hazard Map — real-time road hazard reports on a live map
- 👥 Community Feed — posts, meetups, gear for sale
- 🏍️ My Garage — track bikes and service history
- ⏱️ Ride Timer — live helmet session tracker
- 🤖 AI Scalp Scan — AI-powered scalp health analysis via camera

## Tech Stack
- React + Vite
- Firebase (Auth, Firestore)
- Cloudinary (image storage)
- Leaflet + OpenStreetMap (maps)
- Groq AI (scalp scan analysis)
- Tailwind CSS

## Getting Started

1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/ridelanka.git
cd ridelanka
```

2. Install dependencies
```bash
npm install
```

3. Create `.env.local` and add your keys
```
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
VITE_CLOUDINARY_CLOUD_NAME=
VITE_CLOUDINARY_UPLOAD_PRESET=
VITE_GROQ_API_KEY=
```

4. Run the app
```bash
npm run dev
```
